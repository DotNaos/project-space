# Execute typed Project CLI operations through SSH

Project Space can now run a harmless typed status check against an exact
Environment instance through an approved private-network SSH route. The
gateway verifies authorization, route freshness, target identity, and the
pinned host key before it resolves the scoped credential or dispatches work.

The remote host accepts only a versioned Project CLI control protocol through
a restricted forced command. Durable operation records make exact retries
safe, fence uncertain outcomes, and keep the audit trail free of addresses,
usernames, keys, credentials, and raw command output.
