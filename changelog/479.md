# Redesign Project Chat around Codex tasks

Project Chat now centers the real Codex conversation, groups tasks by online
Tailscale machine in a compact right-hand list, and keeps the composer disabled
until a task is opened. Each machine shows four recent tasks until the list is
expanded. The selected task now loads the live Codex model catalogue.
New Codex tasks can be created from either Project Chat or an issue detail page
after choosing an online machine and one of that project's ready worktrees.
Issue details now embed their linked Codex tasks, native GitHub workflow run,
pull request, and Preview status directly in the Runner and Pipeline tabs.
