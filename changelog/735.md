# Connect an account-owned Tailnet

Each Project Space account can now connect its own Tailnet with a read-only Tailscale OAuth client.
Device refreshes stay isolated by account, credentials are stored behind a dedicated encryption
key, and disconnecting removes the stored credential. The existing VPS-local inventory remains
visible as a temporary source for its configured owner while the isolated network data plane is
completed separately.
