# Discover execution environments through remote MCP

Remote MCP orchestrators can now list and inspect the canonical execution
environments available in Project Space before starting Codex. Results keep
physical hosts optional, show connector and runtime evidence separately, and
remain blocked when identity, freshness, authorization, workspace, or capacity
evidence is incomplete.

Existing machine-based clients remain compatible while new workflows can use
the stable environment identity directly.
