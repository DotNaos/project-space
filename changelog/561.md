# Run safe workspace and recovery commands through MCP

Remote orchestrators can now start, inspect, and cancel bounded asynchronous
commands in the exact workspace owned by a Task Execution. Project Space binds
each command to its owner, Environment, connector generation, workspace, and
Handoff permissions, while keeping Git and workspace write access separate.

Privileged repair commands use an independently authorized GitHub Codespaces
channel and require the user to approve the complete command first. Both paths
retain durable audit and reconciliation state, limit and redact output, and
never fall back to running a command on the Project Space server.
