# Add release notes to the Project Space sidebar

Project Space now shows a dependable What's new notice for each release until
that version is dismissed. The release notes include a collapsible version tree
for older changelogs, and the permanent Info menu now provides both Changelog
and Documentation access.

Pull request Preview links now read the trusted runtime inventory correctly.
When that inventory cannot be verified, the Preview hub reports it as
unavailable instead of incorrectly offering to deploy an already-running
Preview.

Preview domains now act as the stable destination. When sign-in is needed, a
small trusted gate returns the user directly to the requested PR path instead
of leaving them in the Preview manager or Prototype review shell. A persistent
Full preview / Prototype switcher makes both surfaces reachable on the same PR
domain.
