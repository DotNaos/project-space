## Canonical remote development

- Introduce canonical Platform, Host, Environment, route, and Workspace Runtime inventory with private SSH bootstrap and authenticated outbound control.
- Run pinned, generation-owned Workspace Runtimes with durable Codex delivery, safe inspection, bounded mutations, and optional host telemetry and console control.
- Make the canonical compute model primary, deprecate permanent Connector bootstrap, and add a privacy-safe usage gate before final compatibility removal.
