# Canonical remote development and Runtime control

Project Space now distinguishes reusable Environments from concrete instances,
Platforms, optional Hosts, approved private-network routes, and generation-owned
Workspace Runtimes. The Project CLI can discover this privacy-safe inventory and
bootstrap a pinned Runtime over the private typed SSH gateway.

Workspace Runtimes register through an authenticated outbound session, preserve
durable Codex delivery, and expose safe inspection plus bounded Git, Worktree,
task-activation, and declared development-server operations. Exact ownership,
replay, sequence, and crash-recovery evidence prevents stale or uncertain work
from being dispatched again or affecting another Workspace generation.

Optional host telemetry and narrowly scoped Host power control fit the same
inventory without becoming development prerequisites. The canonical compute
hierarchy is now primary, permanent Connector bootstrap is deprecated, and a
private usage ledger must prove a complete zero-use window before the remaining
compatibility paths can be removed.
