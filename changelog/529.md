# Run issue-bound Codex tasks in GitHub Codespaces

Project Space can now create and manage a task's GitHub Codespace directly
from the issue screen. The same screen guides the one-time Project Space
approval and ChatGPT subscription login, then starts Codex in the exact
Codespace without requiring terminal setup or an API key.

Codespaces use a checksum-pinned managed runner that reconnects after a
restart, includes the tools needed to finish work through a pull request, and
reconciles uncertain operations before retrying.
