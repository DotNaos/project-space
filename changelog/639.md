# Run Codex inside Workspace Runtime generations

Workspace Runtime generations can now start and supervise their own Codex App
Server through a generation-local host controller. The controller reuses the
existing typed Codex session executor for reading, continuing, steering,
interrupting, approvals, user input, settings, and live events.

Codex authority becomes active only after the controller reports ready. Every
command is bound to the exact owner, Workspace, Environment, generation,
socket, actor, operation, sequence, and target; durable journals make exact
reconnects replay safely while stale generations remain fenced. The controller
uses protected local pipes and exposes no public listener, shell, generic
process execution, or file API.
