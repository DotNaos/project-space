# Model approved private-network access routes

Project Space can now store owner-scoped private networks and typed access
routes for Environments and Hosts. Route readiness stays blocked until the
network is approved, the exact target identity and gateway match, and both
network and route evidence are fresh.

Tailscale is the first mapped provider, while the same provider-neutral
contract is verified with a WireGuard fixture. The Project CLI negotiates a
new inventory representation that shows only safe network and route summaries;
addresses, SSH users, host keys, provider identifiers, gateway policy, and
credential references remain server-side.
