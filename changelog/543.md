# Authorize managed Codex agents through remote MCP

Remote MCP orchestrators can now inspect the current Codex runtime and complete
ChatGPT device authorization for one exact execution environment. Login starts,
status checks, and cancellation survive retries and connector restarts without
storing device codes, account details, or credentials in Project Space.

Managed environments require a freshly confirmed ChatGPT subscription account.
API keys and stale readiness flags are rejected, while offline, unsupported,
expired, cancelled, denied, and uncertain outcomes remain explicit.
