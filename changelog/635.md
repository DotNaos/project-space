# Stream Workspace Runtime state over an outbound session

Active Workspace Runtimes now report their lifecycle, heartbeat, dev servers,
telemetry, and safe log pointers through a short-lived outbound WebSocket
session. The connection is bound to the exact owner, Workspace, Environment,
runtime generation, source revision, and manifest.

Reconnects resume from durable acknowledgements, newer generations fence older
sessions, and stale runtime data cannot overwrite current state. Typed SSH is
used only to bootstrap or recover the runtime instead of continuously polling
it, and the generation-owned Codex app-server keeps running independently of a
temporary telemetry disconnect.
