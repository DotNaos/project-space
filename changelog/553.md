# Run complete Tasks through remote MCP

Remote MCP orchestrators can now start, list, inspect, wait for, message,
cancel, and archive provider-neutral Task Executions. A normal start coordinates
the selected Environment, capacity, readiness, exact workspace and commit, and
the Codex executor while preserving the existing Codex tool names as aliases.

Approval and input responses are bound to the exact pending request and use a
separate approval permission. Durable operation records safely replay confirmed
work and reconcile uncertain connector outcomes without starting duplicate work.
