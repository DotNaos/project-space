# Separate reusable Environments from concrete instances

Project Space now stores reusable Environment definitions separately from the
concrete machines, sandboxes, and other instances that run work. Existing
instances are linked to matching built-in definitions during migration without
changing their established identity or Connector association.

Inventory reads now include this definition boundary and reject missing or
contradictory links. This provides the first additive foundation for the remote
development architecture while keeping current machine and Connector workflows
compatible.
