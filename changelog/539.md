# Manage GitHub Codespaces through remote MCP

Remote MCP orchestrators can now provision, start, inspect, stop, and delete
task-bound GitHub Codespaces through the same lifecycle used by the Project
Space Web UI. Operations survive lost responses, remain isolated per account,
and stop safely when GitHub, connector, or active-execution evidence is unclear.

Environment management and deletion use separate opt-in permissions. GitHub
reauthorization and Codex or connector readiness are returned as structured
next steps without exposing credentials.
