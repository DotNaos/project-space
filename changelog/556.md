# Hand verified designs between remote agents

ChatGPT, Claude, Codex, and future orchestrators can now create and read one
immutable Task Handoff through the remote MCP. Designs, documents, screenshots,
and decisions are verified and stored by Project Space, so another agent can
consume them on a different machine without depending on a local file path.

Each Handoff records its requested mode and permissions separately from the
briefing. A Task Execution may switch to an exact Handoff revision only before
its executor starts, and the change is preserved in its history.
