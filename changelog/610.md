# Update idle connector runtimes automatically

Outdated machine connectors now install the newest approved release when they
reconnect and the machine is idle. Project Space waits while Codex or another
machine change is active, verifies the connector and managed Codex runtime
together, and keeps failed updates recoverable without starting work on an
incompatible runtime.

The Machines and Codex task views now show available, pending, failed, offline,
and identity-conflict states with the exact reason and recovery action.
