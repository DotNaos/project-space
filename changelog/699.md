# Delete the legacy Connector command hub

Remove the generic Connector command channel and its dev-server, worktree, workspace-command, runtime-maintenance, filesystem, and terminal dispatchers. Legacy machine routes now fail predictably while the canonical Runtime and direct local paths remain available.

Environment bootstrap guidance now lives in the main Project documentation. From a managed worktree, `project environment bootstrap` detects the Workspace, commit, resolved Runtime plan, version, mode, owner, and unambiguous Environment Instance, while manual values remain available for automation.
