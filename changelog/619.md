# Run Project Space entirely on one computer

`project serve` now opens a complete local simulation by default, without an
internet connection, external accounts, hosted databases, API keys, or
1Password secrets. Project, issue, branch, pull request, worktree, development
server, machine, Codex, and deployment journeys use coherent local state that
persists across restarts and can be reset from one neutral indicator in the
app.

Real integrations remain behind explicit API and data choices and fail closed
until secure detached credential delivery is available. Tailnet publication is
also separate from backend selection, so the default runtime stays local-only.
