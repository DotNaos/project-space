# Discover compute inventory through the Project CLI

Agents can now inspect Project Space compute inventory through one versioned,
read-only JSON command. Focused commands list and show Platforms, Hosts,
reusable Environment definitions, and concrete Environment Instances, while
ambiguous human names stop with exact candidate references.

The inventory response excludes private network details, filesystem paths,
credentials, raw identity evidence, and hardware models. Offline capabilities
remain visibly unavailable, provider state stays unknown without provider
evidence, and legacy machine discovery warns before forwarding to Host
discovery.
