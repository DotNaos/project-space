# Steer or queue messages for active Codex tasks

Project Space MCP clients can now steer an exact active Codex turn or queue
follow-up work for automatic delivery when the task becomes idle. Queued
messages keep their order across restarts, retries remain safe, and every
message reports whether it was sent, steered, queued, blocked, completed, or
still needs reconciliation.
