## Summary

Make the Chat page a direct interface to real Codex tasks. The conversation stays in the
center, while a compact task list groups recent sessions by fresh online Tailscale host.

## Problem

The previous Project Chat surface was a separate product experience and did not expose the
real Codex task lifecycle. It also lacked a source-aware host boundary, so it could not safely
offer machine and worktree selection for continuing a task.

## Scope

- Replace the Project Chat surface with the canonical Codex task conversation.
- Discover eligible hosts from fresh deployment-owned Tailscale observations.
- Group tasks by online host and show four per host until expanded.
- Keep machine and worktree selection visible before a task is opened.
- Bind task-detail creation to the selected issue's Project-managed worktree without a
  cross-task worktree picker.
- Keep the composer visible but disabled until a real task is selected.
- Provide a development-only local Codex app-server transport for signed-in dogfooding.

## Out of scope

- Reintroducing Project Chat inside the graphical interface.
- Loading offline or stale Tailscale machines.
- Adding credentials, fixtures, or simulated task data to the signed-in development path.
- Merging or deploying the change without review.

## Delivery

The change is backward compatible at the API level. The Project Chat backend remains
available to CLI users, while the graphical Chat entry now opens the Codex task experience.
