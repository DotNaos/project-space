Project Space changes are developed in issue-specific Project-managed worktrees and
integrated through pull requests. Start with the repository `AGENTS.md`, then use the
guides in this section.

## Contributor path

1. Confirm the owning issue and worktree.
2. Identify affected current requirements and architecture.
3. Create or update the change specification for observable behavior changes.
4. Implement from the hierarchical task checklist.
5. Record reproducible evidence as tasks complete.
6. Reconcile requirements, design, tests, docs, and issue commitments.
7. Run the repository preflight and submit the exact revision for review.
