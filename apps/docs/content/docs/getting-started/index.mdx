Project Space combines a web application, the `project` CLI, remote development
environments, and automation around one project-centered workflow.

## 1. Install the CLI

Follow the [installation guide](/docs/getting-started/installation), then confirm that
the CLI is available:

```sh
project version
```

## 2. Work with a project

```sh
project create my-project
cd my-project
project validate
```

## 3. Choose the next path

- Use [Environments](/docs/getting-started/environments) for remote development.
- Use the [CLI reference](/docs/cli) for exact commands and flags.
- Use [Templates](/docs/templates) to understand template-backed projects.
- Use [Development](/docs/development) when changing Project Space itself.
