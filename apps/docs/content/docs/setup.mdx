## Choose The Installation Source

| Source | Install or update path |
| --- | --- |
| Managed macOS arm64 | Use the pinned installer generated from Project Space Machines; later run `project self-update` |
| Managed Linux x64 or WSL | Install the signed machine-tools bundle from the approved GitHub release; later run `project self-update` |
| Homebrew | Installs and updates the CLI and connector; optionally migrate to signed managed delivery |
| Native Windows | Run the approved per-user installer; `self-update` verifies and points to the next installer |
| Source checkout | Pull and rebuild from source; the updater never overwrites development binaries |

Managed releases install the Project CLI and connector as one matching pair.
They preserve machine identity and credentials when upgraded or migrated from
a supported Homebrew installation.

## Homebrew

```sh
brew tap DotNaos/project-space https://github.com/DotNaos/project-space
brew install --HEAD DotNaos/project-space/project
```

The Project formula installs and updates both the Project CLI and connector.
The standalone connector formula remains supported for connector-only Homebrew
service delivery:

```sh
brew install DotNaos/project-space/project-space-connector
brew services start DotNaos/project-space/project-space-connector
```

Update Homebrew-owned tools normally:

```sh
brew update
brew reinstall --HEAD DotNaos/project-space/project
```

To install the signed managed CLI and connector pair without changing or
removing the Homebrew files:

```sh
project self-update --migrate-managed --check
project self-update --migrate-managed
```

Migration is optional and never happens during a normal Homebrew update or
plain `project self-update`. It shows the exact signed target, managed location,
Homebrew or Project service transition, preserved machine identity and
credential state, and rollback behavior before asking for confirmation. A
successful migration starts the managed connector and returns only after the
exact build has authenticated and reconnected. Homebrew-owned files remain in
place, while a known Homebrew connector service is quiesced so it cannot compete
with the managed service. Use `--yes` for explicit non-interactive confirmation;
JSON remains read-only unless `--yes` is also present.

## Managed Linux And WSL

Download the versioned Linux x64 machine-tools archive and its checksum from the [approved Project Space release](https://github.com/DotNaos/project-space/releases/latest). Verify the checksum, extract the archive, and run its `install.sh` as your normal user. Do not run the installer as root.

After the first managed installation:

```sh
project self-update --check
project self-update
```

## Native Windows

Run the approved `project-space-machine-tools-windows-x64-setup.exe` installer as your normal user. Native Windows checks the signed release with `project self-update --check`, then reports the exact verified installer URL instead of replacing the running `project.exe`.

See the repository guides for the full [Linux/WSL installation](https://github.com/DotNaos/project-space/blob/main/docs/linux-installation.md), [Windows installation](https://github.com/DotNaos/project-space/blob/main/docs/windows-installation.md), and [connector lifecycle](https://github.com/DotNaos/project-space/blob/main/docs/connector.md).

## First Project

```sh
project create my-project
cd my-project
```

For an existing directory:

```sh
project init
```

Continue with the generated [CLI reference](/docs/cli) or the focused [self-update guide](/docs/cli/self-update).
