---
title: Changelog authoring
description: Add the required raw changelog for every pull request.
---

Every pull request that changes the product must add exactly one immutable
Markdown file at `changelog/<PR-number>.md`. The filename is the pull request
number, not the issue number and not a generated UUID.

```md
---
bump: patch
---

# Short summary

Explain what changed and why it matters.
```

`bump` is required and must be `patch`, `minor`, or `major`. There is no
`none`: every merged pull request receives a concrete version. The pull
request keeps `package.json` unchanged; after merge, the serial release queue
assigns the next version in main-branch order.

The raw file is the source record. It is shown in the Docs **Unreleased**
Inbox until the release queue can associate it with a published version. This
means a release-documentation problem cannot make a changelog disappear.

Do not edit another pull request's changelog file or historical files under
`apps/docs/content/docs/releases/entries/`.
