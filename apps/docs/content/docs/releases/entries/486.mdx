<ReleaseSummary>
  ChatGPT can now authorize the Project Space MCP server without a Clerk OAuth
  application or client secret.
</ReleaseSummary>

## Changes

### Added

- Added a Project Space OAuth 2.1 authorization server with dynamic client registration and PKCE.
- Added rotating refresh tokens, hashed persistent credentials, and separate read and write scopes.
- Added a browser consent page that uses the existing Clerk login only to identify the user.

### Removed

- Removed the Clerk OAuth Applications dependency from the MCP server.
