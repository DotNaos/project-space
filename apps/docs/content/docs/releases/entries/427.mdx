<ReleaseSummary>
  Project Space Previews can be registered offline, started when needed, and
  stopped without automatically replacing another review environment.
</ReleaseSummary>

## Changes

### Added

- A trusted Preview hub lists eligible pull requests and provides explicit start, stop, and replacement choices within the three-runtime limit.
- Offline Preview records retain the exact change identity and storage evidence while deep links return safely through the authenticated hub.
- Idle review runtimes can return to a ready offline state after their trusted activity lease expires.

### Security

- Preview lifecycle actions require Project Space authentication and exact repository, pull request, head, and health verification.
- Preview credentials and host controls remain outside pull-request application code, and production resources remain isolated from Preview failures.
