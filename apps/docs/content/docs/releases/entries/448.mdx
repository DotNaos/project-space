<ReleaseSummary>
  Browser tabs now identify both the selected project and its Tasks page, making
  open Project Space tabs easier to distinguish.
</ReleaseSummary>

## Changes

### Fixed

- Tasks pages now show the selected project name in the browser tab title.
- Changing projects updates the title, while leaving Tasks restores the default Project Space title.
