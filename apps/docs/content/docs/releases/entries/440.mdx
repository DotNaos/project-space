<ReleaseSummary>
  Codex tasks now draw from a much larger clean-name pool and safely recycle
  inactive online and local reservations through renewable leases.
</ReleaseSummary>

## Changes

### Added

- Added 16,384 deterministic clean names for automatic Codex task allocation.
- Added renewable 48-hour leases for online and locally locked reservations.
- Added a versioned installer and integrity check for the global startup skill.
- Added a repository check that keeps installs, builds, and automation on the pinned Bun version.

### Fixed

- Live local reservations are excluded before an online name claim is made.
- Local installation and locks work on macOS, Linux, and Windows; large reservation sets use a bounded exclusion file instead of overflowing process arguments.
- Incomplete or unstructured task listings never reclaim active leases.
- Name changes and specialist joins update the claim, current member identity, and presence atomically against the current parent.
- Concurrent activity renews only the exact claim version it authorized, so it cannot undo a newer rename.
- A clean offline name is preferred when connectivity returns, preserving the same task identity unless that name is already claimed.
- Specialists refresh their qualified identity after a parent rename, and restored snapshots keep an active member's handle reserved.
- Existing claims receive a full first lease window during upgrade, and automatic allocation skips names whose mention handle is already active.
- Expired claims can be reused without rewriting historical Project Chat senders.
- Genuine name exhaustion remains distinct from connectivity and contract failures.
- Mobile prototype builds now use a frozen Bun lockfile in local, CI, preview, and release paths, avoiding the separate runtime download that made preview builds unreliable.
- The package-manager gate verifies the exact Bun runtime and catches competing commands even without arguments or before shell operators.
- Exact-artifact Preview builds include the tools required to validate the package-manager policy.
- The large name-allocation regression check now exercises allocations concurrently, preserving the stress coverage without depending on machine speed.
