  Automatic pull request Previews can now retry cleanly after an earlier
  deployment attempt failed.

## Changes

### Fixed

- A failed Preview deployment can re-enter the verified apply path and become online after a successful retry.
- Failed retries keep their failed state when repository preparation still cannot complete.
