- Successful pull request artifact builds now start their trusted Preview deployment automatically.
- Preview deployments report their exact GitHub deployment result and sanitized transition evidence.

### Fixed

- Trusted Preview gateways receive the verification state required to serve the deployed revision.
- A ready Preview can transition directly online when the trusted workflow applies its exact artifacts.
