<ReleaseSummary>
  Project Space now centers each project around a compact workspace, real task
  lifecycle data, and direct paths to development, review, and cleanup.
</ReleaseSummary>

## Changes

### Added

- Added the task-first project sidebar and responsive project workspace.
- Added real GitHub issue, branch, pull-request, pipeline, and discussion data to task views.
- Added guided task states for backlog, draft development, active review, and merged cleanup.
- Added automatic exact-revision PR Preview deployment after a successful Preview artifact build.

### Changed

- Consolidated project navigation around Tasks, Chat, Repository, Machines, and Templates.
- Kept prototype, Design Space, development-server, and machine context close to active tasks.
- Replaced the previous issue workspace with the reviewed responsive task experience.
