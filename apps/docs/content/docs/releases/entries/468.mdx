<ReleaseSummary>
  Pull requests now use one fast, path-aware CI result, keep their exact-head
  Preview, and only build development CLI and connector bundles when requested.
  Production deploys and versioned tool releases now have separate, explicit
  paths without adding a permanent staging or release branch.
</ReleaseSummary>

## Changes

### Added

- Added manual, short-lived, unsigned PR development bundles for the Project CLI and connector.

### Changed

- Consolidated ordinary pull-request validation into one path-aware Fast CI result.
- Consolidated Preview lifecycle, cleanup, and reaping while retaining the trusted deployment boundary.
- Separated ordinary Production deployments from explicit versioned tool-release pull requests.
- Documented the one-time branch-protection switch to Fast CI and Release decision after rollout.

### Removed

- Removed obsolete Preview wrapper, release handoff, and signing-probe workflows.
