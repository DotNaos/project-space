<ReleaseSummary>
  Pull request Previews now build with the exact revision's own recipes before a
  trusted workflow verifies and promotes immutable image artifacts.
</ReleaseSummary>

## Changes

### Added

- Exact-head Preview builds publish a canonical manifest and GitHub-attested image archives without Preview credentials or registry write access.
- Trusted promotion verifies repository, pull request, revision, workflow run, artifact identity, bounded file inventory, and every archive checksum before import.

### Fixed

- Preview validation no longer combines an older `main` Docker recipe with a newer pull request source tree.
- The trusted deployment workflow never checks out or executes pull request source and passes only immutable registry digests to the existing runner.
- Closed-pull-request cleanup remains a separate trusted workflow with the same exact-resource tombstone checks.

## Upgrade notes
